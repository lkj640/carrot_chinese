문법是 · 什么 · 的

① A 是 B = A는 B예요

我是中国人。 저는 중국 사람이에요.
我是美国人。 저는 미국 사람이에요.

부정은 不是 bú shì: 我不是学生。 저는 학생이 아니에요.

② 什么 = 무엇 (묻는 자리에 그대로)

你叫什么名字？ 이름이 뭐예요?
→ 我叫汤姆。 저는 톰이에요.

대답할 때는 什么 자리에 답을 넣기만 하면 돼요. 어순이 그대로예요!

③ 사람 + 的 + 명사 = ~의

你的中文很好！ 당신의 중국어는 아주 좋아요!
我的名字 제 이름

④ 还在 + 동사 = 아직 ~하는 중

我还在学习。 아직 배우는 중이에요.
칭찬받으면: 谢谢！我还在学习。

⑤ 我也觉得… · 我们可以一起…

我也觉得这里很好。 저도 여기가 좋다고 생각해요.
我们可以一起学习中文。 우리 같이 중국어 공부하면 되겠네요.

문법哪 · 在 + 장소 · 会와 可以

① 哪 + 国 + 人？ = 어느 나라 사람?

你是哪国人？ 어느 나라 사람이에요?
→ 我是韩国人。 한국 사람이에요.

哪 nǎ 어느 ↔ 那 nà 그것 — 성조가 달라요!

② 在 + 장소 + 동사 = ~에서 …하다

你在哪儿工作？ 어디에서 일해요?
→ 我在北京工作。 베이징에서 일해요.

1주차 我在学习(지금 ~하는 중)와 달리 在 뒤에 장소가 와요.

③ 会 = (배워서) 할 줄 안다

你会说英文吗？ 영어 할 줄 알아요?
→ 会，我会说英文。 / 不会。 / 会一点儿。

④ 可以 = ~해도 된다 · ~할 수 있다

我可以坐这儿吗？ 여기 앉아도 돼요?
→ 当然可以！请坐。 물론이죠! 앉으세요.
我可以教你。 제가 가르쳐 드릴 수 있어요.

⑤ 동사 + 得 + 很好 = ~를 잘하다

说得很好！ 말을 잘하네요! · 你做什么工作？ 무슨 일 하세요? (做 = 하다)

문법从…来 · 以前/现在 · 吧

① 从 + 장소 + 来 = ~에서 왔다

你从哪儿来？ 어디에서 왔어요?
→ 我从加拿大来。 캐나다에서 왔어요.
→ 我从韩国来。 한국에서 왔어요.

② 以前 ↔ 现在

你以前做什么工作？ 전에는 무슨 일 했어요?
我以前是医生。 전에는 의사였어요.
现在我想换工作。 지금은 일을 바꾸고 싶어요.

중국어는 동사 모양이 안 바뀌어요. 以前·现在 같은 시간 낱말로 때를 나타내요.

③ 大家好！ = 여러분 안녕하세요!

여러 사람 앞에서 자기소개를 시작할 때:
大家好！我叫陈丽。

1주차 공식 "사람 + 好" 그대로예요. (老师好 · 大家好)

④ 문장 끝 吧 = ~하자 (제안)

我们一起工作吧。 우리 같이 일해요.
我们可以互相帮助。 우리 서로 도울 수 있겠네요.
→ 好主意！ 좋은 생각이에요!

⑤ 我学中文 · 我学英文 — 学 + 언어

我学中文。 저는 중국어를 배워요. · 加拿大很远啊！ 캐나다는 정말 멀네요! (문장 끝 啊 = 감탄)

문법기간 · 횟수 말하기

① …多久了？ = ~한 지 얼마나 됐어요?

你来中国多久了？ 중국에 온 지 얼마나 됐어요?
你住在这儿多久了？ 여기 산 지 얼마나 됐어요?

多久 duō jiǔ = 얼마나 오래

② 동사 + 了 + 기간 (+ 了)

我来了三个月。 온 지 석 달 됐어요.
我学了两年。 2년 배웠어요.
我住了十年了。 10년째 살고 있어요. (끝의 了 = 지금도 계속)

③ 얼마나 자주? 每天 · 一周 + 숫자 + 次

你每天来健身房吗？ 헬스장에 매일 와요?
→ 不是每天，一周三次。 매일은 아니고, 일주일에 세 번이요.
我一周锻炼两次。 저는 일주일에 두 번 운동해요.

④ 二 èr 과 两 liǎng

숫자 2를 셀 때는 二, 개수·기간 앞에서는 两.
两年 · 两次 · 两个月 ↔ 二月 · 第二 · 十二

⑤ 来 + 동사 = ~하러 오다 · 有什么需要帮忙的，找我

你也来锻炼吗？ 당신도 운동하러 왔어요? · 有什么需要帮忙的，找我。 도움이 필요하면 저를 찾아요.

一周几次？ 일주일에 몇 번?

几는 대개 10보다 작은 수를 물을 때 써요.

② 你的呢？ = 당신의 것은요?

在三年级。你的呢？ 3학년이에요. 댁의 (아이)는요?

앞에 나온 명사(孩子)는 빼고 的만 남겨요. 我的孩子也在三年级。

③ 可能 = 아마 ~일 거예요

真巧！他们可能是同学。 이런 우연이! 아이들이 같은 반일지도 몰라요.

④ 취미 말하기

你喜欢摄影吗？ 사진 찍는 거 좋아해요?
→ 非常喜欢！这是我的爱好。 정말 좋아해요! 제 취미예요.
我的爱好是摄影。 제 취미는 사진이에요.

⑤ 有很多 + 명사 · 一些 + 명사

我们有很多共同点。 우리는 공통점이 많아요. · 我可以教你一些技巧。 요령을 좀 가르쳐 드릴게요.

자기 점검이제 할 수 있나요?

  • 이름을 말하고 상대 이름을 물을 수 있다. (我叫… · 你叫什么名字？)
  • 국적을 묻고 대답할 수 있다. (你是哪国人？ · 我是韩国人)
  • 직업과 일하는 곳을 말할 수 있다. (我是… · 我在…工作)
  • 会와 可以를 구분해 쓸 수 있다.
  • 얼마나 됐는지·얼마나 자주 하는지 말할 수 있다. (多久了 · 一周三次)
  • 7문장 자기소개를 중국어로 발표할 수 있다.
