문법반가워요 두 가지 · 很 + 형용사 · 也

① 반가워요 = 두 가지 모두 OK

认识你很高兴。 (너를 알게 되어 기뻐)
很高兴认识你。 (기쁘다, 너를 알게 되어)

대답: 我也很高兴。 / 我也是。

② 주어 + 很 + 형용사

你的名字很好听。 이름이 예쁘네요.
你的名字很可爱。 이름이 귀엽네요.

형용사 앞에는 是를 쓰지 않아요. ✗ 名字是好听 · 很은 "아주"라는 뜻이 약해서 습관처럼 붙여요.

③ 我也是 + 명사 = 저도 ~예요

我也是中国人。 저도 중국 사람이에요.
짧게: 我也是。 저도요.

也는 동사(是) 앞! ✗ 我是也

④ 新 + 명사 = 새 ~

你是新学生吗？ 새로 온 학생이야?
新同学 · 新朋友 새 반 친구 · 새 친구

⑤ 请问 = 공손하게 묻기 시작

你好，请问你叫什么？ 안녕하세요, 실례지만 이름이 뭐예요? · 대답할 때는 请问을 안 써요.

문법贵姓 · 姓과 叫 · 可以…吗 · 常

① 姓 = 성 · 叫 = 이름 전체

我姓周。 저는 저우씨예요.
我叫周杰。 저는 저우제예요.

중국 이름은 성 + 이름: 周 + 杰 · 刘 + 老师 = 류 선생님

② 请问你贵姓？ = 성함이?

请问你贵姓？ → 我姓刘。
→ 되묻기: 我姓刘。你呢？

대답할 때 ✗ 我贵姓刘 ✗ 我姓刘老师

③ 我可以 + 동사 + 吗？ = ~해도 돼요?

我可以问一下吗？ 뭐 좀 물어봐도 돼요?
→ 可以，请问。 그럼요, 물어보세요.

동사 + 一下 = 좀 ~하다 (가볍게): 问一下 · 写一下

④ 常 + 동사 = 자주 ~하다

你常来这里吗？ 여기 자주 와요?
→ 是的，我常来。 네, 자주 와요.

⑤ 이름 + 欢迎你！ · 谢谢 + 호칭

周杰，欢迎你！ 저우제 씨, 환영해요! · 谢谢刘老师。 감사합니다, 류 선생님. · 那很好。 그거 좋네요.

문법谁的 · 好像 · 都 · 是…的

① 谁 = 누구 · 谁的 = 누구의

我也是他的朋友。 저도 그의 친구예요.

谁는 shéi (shuí라고도 읽어요)

② 好像 = ~인 것 같다

我们好像没见过。 우리 처음 보는 것 같네요.

동사 + 过 = ~한 적 있다 · 没 + 동사 + 过 = ~한 적 없다
见过 · 没见过

③ 都 = 모두 (동사 앞)

那我们都是朋友了。 그럼 우리 다 친구네요.
我们都是中国人。 우리는 모두 중국 사람이에요.

끝의 了 = 이제 그렇게 됐다 (변화)

④ 是…的 · 一个人

我昨天搬来的。 어제 이사 왔어요. (언제 했는지 강조, 1주차 복습)
